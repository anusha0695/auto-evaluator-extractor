# Reproducible install for the extractor pipeline.
#
# By design, this file has NO version pins except langchain-google-genai==4.2.2
# (the only version that's been validated with our wrapper code). Every other
# package is left to pip's resolver — transitive constraints from the packages
# themselves (spaCy → scispacy compatibility, etc.) keep the set coherent.
#
# Install:
#   python3.12 -m venv .venv && source .venv/bin/activate
#   pip install --upgrade pip
#   pip install -r requirements.txt
#
# Verify the in-process Medical NER models loaded:
#   python -c "import spacy; nlp = spacy.load('en_ner_bionlp13cg_md'); print(nlp.pipe_names)"

# ===== LangGraph + LangChain =====
# Phase 1 uses LangGraph's built-in MemorySaver. Phase 4 swaps in our own
# FirestoreCheckpointer when SME interrupt/resume arrives.
#
# Gemini wrapper: `langchain-google-genai` 4.2.2 — built on the newer
# `google-genai` SDK that unifies Google AI Studio (dev, API key) and
# Vertex AI (prod, BAA-covered) through a single `GOOGLE_GENAI_USE_VERTEXAI`
# env flag. This is the ONLY pinned package — its API surface drives the
# extractor wrapper code, so it must not float.
langgraph
langchain-core
langchain-google-genai==4.2.2
langchain                                        # for @tool decorator
