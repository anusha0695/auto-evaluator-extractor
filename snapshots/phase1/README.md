# Phase 1 snapshot

Frozen copy of the Phase 1 demo set. Generated by `scripts/snapshot_phase.py --phase 1`.

Contents:
  - `ui/`          — the Phase 1 Streamlit app, runnable as `streamlit run snapshots/phase1/ui/app.py`
  - `graph_v1.py` — the frozen pipeline graph composition.
  - `MANIFEST.md`  — the Phase 1 shipping manifest at the time of the snapshot.

This directory is **read-only by convention** — Phase 2+ work should not modify these files. The snapshot exists so the Phase 1 demo can be replayed after later phases ship.
